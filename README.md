# Template Method - Xử lý thanh toán

## Chạy trong VS Code
1. Cài extension "Extension Pack for Java" (và JDK 11 trở lên).
2. Giải nén, dùng File > Open Folder để mở thư mục này.
3. Mở Main.java, bấm nút Run phía trên hàm main (hoặc F5).

## Chạy bằng terminal
```
javac -encoding UTF-8 *.java
java Main
```

Nếu tiếng Việt bị lỗi font trong terminal Windows, chạy trước: `chcp 65001`.
